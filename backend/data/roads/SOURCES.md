# Road geometry sources

| File | Status | Notes |
|---|---|---|
| `sample_major_roads.geojson` | **SAMPLE / APPROXIMATE** | 22 hand-placed polylines through landmark coordinates (real road names, approximate positions, can be 100-300 m off). Generated by `scripts/build_sample_roads.py`. Two unnamed service lanes are included deliberately. |

Real road geometry could not be downloaded in the build environment (Overpass API and OpenCity are not reachable there).
To load real data on a machine with internet access:

* OpenStreetMap: `python scripts/fetch_osm_roads.py` (Overpass, chunked by ward bounding box; ODbL licence, credit "OpenStreetMap contributors").
* BBMP road centerlines or any GeoJSON / Overpass JSON file: `python scripts/load_roads.py --file <path> --source "<name>" `.
* Or call the admin API (`POST /api/admin/geography/roads`, `/api/admin/geography/wards`; interactive docs at `/docs`).
