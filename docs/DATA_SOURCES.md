# Data sources and provenance

| Data | Origin | Status |
|---|---|---|
| Ward boundaries, 243 wards (2022) and 198 wards (2012) | DataMeet Municipal_Spatial_Data (KGIS / KSRSAC and Open Bangalore), CC BY-SA 2.5 India. Repaired with `shapely.make_valid`, rounded to 6 decimals (`scripts/prepare_ward_data.py`). Details: `backend/data/wards/SOURCES.md` | Real boundary data, bundled |
| GBA 369-ward map (Nov 2025) | GBA via OpenCity | **Not loaded** (not downloadable here). Loader: `scripts/load_wards.py` |
| Road geometry | `data/roads/sample_major_roads.geojson`: 22 hand-placed approximate polylines with real road names (`scripts/build_sample_roads.py`) | **SAMPLE / APPROXIMATE**, flagged `is_approx` + `is_demo` |
| Real road geometry | OpenStreetMap via Overpass (ODbL) | **Not loaded**. `scripts/fetch_osm_roads.py` + `load_roads.py` |
| Work orders / payments | `data/sample/sample_work_orders_243.csv`, generated by `scripts/build_sample_data.py` | **SAMPLE, synthetic**. Job numbers start `SAMPLE/`, contractor names are invented, `Data Status` column says so, rows are stored with `is_demo` |
| Tenders | `data/sample/sample_tenders_kppp.csv` | **SAMPLE, synthetic** (same marks) |
| PDF documents | `data/sample/documents/` (19), `data/heldout*/` (12): generated with reportlab; X01 and Z01 are deliberate orphan / unrelated documents, C01 a scan | **SAMPLE, synthetic**; text begins with a "SAMPLE" notice |
| Citizen complaints | `data/eval/complaints_labelled.json` (85, with ground-truth group labels) | **SAMPLE, synthetic**; every row has `is_demo`, references start `DEMO`, and the interface shows a banner |
| Gold files for evaluation | `data/eval/*.json` | Written by the developers alongside the synthetic data |
| Basemap tiles | OpenStreetMap contributors | Loaded from the public tile server at view time |

**Where real data should come from** (not done here): BBMP work orders and payments on OpenCity (https://data.opencity.in), Karnataka Public Procurement Portal (https://kppp.karnataka.gov.in, manual collection), BBMP/KGIS road and ward layers, OpenStreetMap. Check each licence and date before use. A work order is a record of a decision; it is not proof that work was done.

Sample records are never merged into official columns without a flag: every sample row carries `is_demo`, the interface shows a banner whenever sample data is present, and `SAMPLE (synthetic, not a government record)` is stored as the source name.
